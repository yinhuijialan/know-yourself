# 认识你自己

一款基于心理类型偏好探索的中文 Web 应用，用一组原创问题帮助用户理解当下更自然的能量、信息、决策与生活组织偏好。

## 当前功能

- 64 道五级作答的原创探索问题；
- 可返回修改、未答检查与本地进度保存；
- 四维偏好组合、清晰度和温和的结果提示；
- 无需登录，原始答题数据默认只保存在浏览器本地。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://localhost:3100](http://localhost:3100)。本项目固定使用 3100 端口，避免与其他本地项目冲突。

## 提示

结果是自我探索参考，不是心理诊断，也不应用于招聘、医疗或重大决策。
